# ⚡ JEN AI — Futuristic Groq Chatbot

A high-performance, cyberpunk-themed AI chatbot built with **Flask / Python** and the **Groq API**, loaded securely from [.env](file:///c:/Users/ZAIM%20KHAN/OneDrive/Desktop/jen%20ai/.env).

![JEN AI Avatar](/static/assets/avatar.jpg)

---

## ✨ Features Included

1. **Animated Video & Avatar Visualizer**:
   - Cybernetic AI companion avatar with reactive soundwave halo and holographic rings.
   - Dynamic states: Idle, Thinking, Listening, and Speaking.
2. **Vibrant Colorful Backgrounds**:
   - 4 Dynamic animated mesh gradient themes:
     - 🌸 **Cyberpunk Neon** (Magenta & Cyan)
     - 🌌 **Cosmic Aurora** (Emerald & Violet)
     - 🌅 **Sunset Synthwave** (Amber & Coral)
     - 🌊 **Electric Ocean** (Azure & Aquamarine)
   - Real-time particle connection physics canvas.
3. **Multi-Voice Audio & Background Ambiance**:
   - **TTS Voice Selector**: Choose between multiple female, male, and studio personas.
   - **Background Audio Generator**: Procedural background ambiance (Chill Lo-Fi, Cosmic Drone, Cyberpunk Rain) with independent volume slider.
   - **Microphone Voice Input**: Speech-to-text integration to talk to Jen AI directly.
4. **CapCut-Style "Move-Up" Kinetic Animations**:
   - Word-by-word kinetic subtitle ticker where words rise and move up as the AI speaks.
   - Smooth "Move-Up" floating chat bubbles.
   - Configurable animation presets (`Move Up`, `Pop & Rise`, `Karaoke Flow`).

## 🚀 How to Run

### Method 1: One-Click Batch Launcher (Windows)
Double-click [start.bat](file:///c:/Users/ZAIM%20KHAN/OneDrive/Desktop/jen%20ai/start.bat) in the project folder.

### Method 2: Command Line
Open PowerShell or Command Prompt in this folder and run:
```powershell
python app.py
```

Then open your browser to:
👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## 🔑 Configuration
Your Groq API key is already configured in [.env](file:///c:/Users/ZAIM%20KHAN/OneDrive/Desktop/jen%20ai/.env):
```env
GROQ_API_KEY=gsk_...
PORT=5000
```
You can also change the key or select different Groq models (Llama 3.3 70B, Llama 3.1 8B, Mixtral 8x7B) anytime from the UI settings gear.
